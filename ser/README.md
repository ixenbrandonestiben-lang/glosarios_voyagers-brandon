# Glosario: Ser

Este README define el formato y las normas que debe seguir cada aporte dentro del **Glosario Ser**.

## Estructura del Término

Cada palabra agregada al glosario debe incluir los siguientes tres elementos:

1. **Término:** la palabra o concepto a definir.
2. **Descripción:** explicación clara y concisa del significado del término.
3. **Ejemplo de aplicación:** un caso o situación donde se aplique el término en la práctica.

## Formato sugerido

```markdown
### Término

**Descripción:**
[Descripción del término]

**Ejemplo de aplicación:**
[Ejemplo donde se aplique el término]
```

## Ejemplo

```markdown
### Empatía

**Descripción:**
Capacidad de comprender y compartir los sentimientos de otra persona, poniéndose en su lugar.

**Ejemplo de aplicación:**
Un líder de equipo escucha activamente las preocupaciones de un compañero antes de tomar una decisión que lo afecta directamente.
```

## Recordatorios

- Cada integrante debe aportar **dos palabras** para este glosario.
- Verificar que el término no esté ya registrado antes de agregarlo.
- Ambos términos de una misma persona deben incluirse en un **único commit**.
- Trabajar únicamente sobre la rama `dev/ser`.
