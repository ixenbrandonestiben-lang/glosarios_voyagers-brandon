# Glosario: Inglés

Este README define el formato y las normas que debe seguir cada aporte dentro del **Glosario Inglés**.

## Estructura del Término

Cada palabra agregada al glosario debe incluir los siguientes cuatro elementos:

1. **Término:** la palabra en inglés a definir.
2. **Traducción:** la traducción del término al español.
3. **Descripción:** explicación del significado del término, redactada tanto en inglés como en español.
4. **Ejemplo en inglés:** una oración de ejemplo que use el término en contexto, escrita en inglés.

## Formato sugerido

```markdown
### Term (Término)

**Traducción:**
[Traducción al español]

**Description (English):**
[Descripción en inglés]

**Descripción (Español):**
[Descripción en español]

**Example (English):**
[Oración de ejemplo en inglés]
```

## Ejemplo

```markdown
### Deadline (Fecha límite)

**Traducción:**
Fecha límite

**Description (English):**
The latest time or date by which a task or project must be completed.

**Descripción (Español):**
La fecha u hora límite en la que una tarea o proyecto debe estar terminado.

**Example (English):**
The team submitted the report before the deadline.
```

## Recordatorios

- Cada integrante debe aportar **dos palabras** para este glosario.
- Verificar que el término no esté ya registrado antes de agregarlo.
- Ambos términos de una misma persona deben incluirse en un **único commit**.
- Trabajar únicamente sobre la rama `dev/ingles`.
